# AI Usage Documentation

## Tools Used

- ChatGPT: Helped plan the database schema, Flask routes, HTML templates, and skill-matching algorithm.

## Key Prompts

- “Help me build this job application tracker assignment step by step.”
- “Write Flask CRUD routes for the companies table using MySQL.”
- “Help format salary ranges as currency and display required skills clearly.”
- “Help me create a function that compares user entered skills with job requirements.”
- “Help me understand this Flask BuildError.”

## What Worked Well

- ChatGPT helped break the assignment into smaller steps to make it easier to complete.
- The code examples it provided helped me create database connections, CRUD pages, and the Job Match feature.
- Explanations helped me identify problems such as a missing Flask route and a template in the wrong folder.

## What I Changed

- I adapted the examples to match my database tables, field names, project folders, and MySQL setup.
- I entered and edited sample records to check that the pages and database worked together.
- I corrected errors after checking the application in PyCharm, MySQL Workbench, and my browser.

## Lessons Learned

- AI-generated code needs to be reviewed and tested in the actual project.
- Small details like route names, template locations, and database credentials can cause errors.
- Testing each feature as it is built makes problems easier to find.
- AI was useful for explanations and starter code, while I integrated and checked the application.
